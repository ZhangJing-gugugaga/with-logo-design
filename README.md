## Skill 能力

一套可复现的品牌标志创作流程 + 30+ 种创意手法：

- **核心心法**：关联（品牌名×行业双咬合）、结合（找共同结构）、规范化（圆/布尔）、记忆点
- **6 大模块 33 手法**：创意构建（找切入点/换思维/发现细节…）、图形构造（圆切大法/布尔运算/同构/正负形…）、字体设计（笔画共用/汉字演化/矛盾空间…）、视觉表现（设计减法/描边大法/留白/视觉平衡…）、色彩调性（人民币配色/颜色叠加/行业匹配）、商业落地（记忆点/象征元素/传统纹样）

## 安装

将 `weizi-logo-design/` 目录放入 Skill 根目录（如 `.user_skills/`）即可。
