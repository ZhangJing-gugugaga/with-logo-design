## Skill 能力

一套可复现的品牌标志创作流程 + 30+ 种创意手法：

- **核心心法**：关联（品牌名×行业双咬合）、结合（找共同结构）、规范化（圆/布尔）、记忆点
- **6 大模块 33 手法**：创意构建（找切入点/换思维/发现细节…）、图形构造（圆切大法/布尔运算/同构/正负形…）、字体设计（笔画共用/汉字演化/矛盾空间…）、视觉表现（设计减法/描边大法/留白/视觉平衡…）、色彩调性（人民币配色/颜色叠加/行业匹配）、商业落地（记忆点/象征元素/传统纹样）
- **案例模板库**：`examples/case-library.md` 收录作者真实 logo 作品拆解 + "行业→手法"反查表，AI 按同行案例模式出稿
- **证据分级**：每个手法标注 `[确认·多源]` / `[确认·单源]`，调用时优先可靠手法
- **M7 高雅极简专项**：作者原话级"高级感"准则（显贵=笔画共用、高级=高挑纤细/衬线断开、科技感=描边+连接处裁剪）
- **G 出图约束**：交图像工具出图前必须带约束（单色/留白/无装饰），防止生成器加料导致"俗"

## 安装
