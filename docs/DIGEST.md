# DIGEST — 维兹 logo 设计方法论精华

> 阶段 5 (交付) 产物 — 不读全部视频，只看这一篇

## 一句话

**所有 logo 设计的本质：把品牌名称的特征和行业属性，通过"找共同点+结合"变成一个规范化、有记忆点的图形。**

---

## 核心心法（4 条，全部视频都在反复讲）

1. **关联**：logo 必须同时咬住"名称特征"（首字母/笔画/谐音/字义）和"行业属性"（行业符号/产品/场景）。占一头必失败。
2. **结合**：找到两个事物的共同结构或共同语义，融合成一个新图形。同构、替换、正负形、笔画共用，全是"结合"的不同招式。
3. **规范化**：草图随手画，最终用圆/辅助线/布尔运算修规整，才有设计感。
4. **记忆点**：加一个"超常规细节"（溢出的咖啡、咬一口的苹果），让人一眼记住。

---

## 六大模块 33 种手法（按需取用）

### M1 创意从哪来（5）
- **找切入点**：谐音/视觉联想/发散（星星+芒果、礼物盒子、民宿湖倒影）
- **换个思维**：常见图形换角度重读（猫→酒杯→叉子）
- **发现细节**：物体局部藏着另一个物（梨把儿=鱼、柠檬=太阳）
- **大道至简**：最小改动最大效果（加两个点）
- **新奇角度**：常见元素非常规组合（浪花进镜头）

### M2 图形怎么做（9）
- **圆切大法**：万物皆可圆（2圆=叶、3圆=盾、4圆=蝙蝠）
- **布尔运算**：加减交出新形（BP 18圆、蝴蝶、天鹅）
- **同构/异形同构**：找共同结构合二为一（音符+天鹅、a+牛奶+咖啡）
- **替换**：用 A 换 B 的相似部件（飞机换香蕉、怀表圈换狼）
- **正负形**：负空间藏第二图（鲁宾杯、咬一口、叶子进 a）
- **外轮廓**：换外轮廓承载新形象（熊头换橙子）
- **有机图形**：几何(理性) vs 有机(自然) 按气质选
- **点线面**：抽象概括
- **多元素组合**：堆砌成新形（12生肖成C字/成虎）

### M3 字体怎么设计（6）
- **笔画共用/共生**：共享笔画连接多字（NB、品字、手表+时针）
- **黑体删减**：黑体打底删笔画变形（民宿、素装）
- **汉字演化+国风**：汉字变形结合元素/纹样（中+铜钱、飞檐替换横笔画）
- **表现主义**：去笔画=遗忘、拆散=破碎、替换=空间感
- **矛盾空间**：阴影错位制造空间幻觉
- **笔画延长/字母组合**：g延长=b、断开倾斜组字

### M4 视觉怎么表现（7）
- **设计减法**：去细节保留特征（去衣帽仍是女装）
- **描边大法**：找图描边+规范（万物起点）
- **放大/倾斜/留白/重复/一笔画**：单动作出设计感
- **立体感/光影**：黑白灰渐变=空间（莫比乌斯环）
- **视觉平衡**：绝对对称 vs 相对平衡、视觉补偿
- **格式塔线条**：规律线条让大脑补全（扭曲出 E）
- **卡通形象上色法**：手电筒明暗分层取色

### M5 色彩怎么选（3）
- **人民币配色**：借色系定调（1元质朴/5元温柔/10元雅致/20元温馨/50元绿茵/100元红——**禁用国徽/人像/文字**）
- **颜色叠加**：叠加出第三形（万事达卡、气泡+闪电）
- **行业属性匹配**：香水=女性化高级感、工业=稳重、律所=罗马柱权威、咖啡=超级符号

### M6 怎么落地（3）
- **记忆点设计**：加超常规细节（咖啡溢满）
- **象征元素**：用公认符号表达抽象（深夜课堂→灯、曲线美→天鹅）
- **传统纹样结合**：提取象征+融合纹样（春晚四马+云雷纹、火虎）

## 一次 logo 设计的完整执行路线

```
解析需求(名称+行业+风格)
  → 拆特征(名称特征2-4个 + 行业特征2-4个)
  → 选手法(查M1-M6，按"有什么特征"匹配)
  → 草图结合(找共同结构/共同语义融合)
  → 规范化(圆切/布尔/辅助线修轮廓，删减细节)
  → 配色(行业调性 + 可选人民币色系)
  → 记忆点校验(加一个超常规细节)
  → 视觉校验(平衡/倾斜/留白/缩小可识别)
```
