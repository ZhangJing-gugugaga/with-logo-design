# candidates/ — 阶段 1 原始候选池（审计用）

> 5 个提取器串行执行（降级方案），产出格式与原并行方案一致

## 1. framework-extractor（决策框架）

1. **logo 创作总流程**：解析需求 → 提取名称特征 → 提取行业特征 → 选手法 → 草图结合 → 规范化(圆/线/布尔) → 配色 → 记忆点校验 → 简化
2. **手法选择决策**：名称有相同笔画→共用；名称有谐音→切入点；行业有符号→结合/替换；要求抽象概念→象征元素；要求极简→减法
3. **同构操作框架**：找共同结构 → 替换/融合 → 调整轮廓 → 配色
4. **几何规范化框架**：画草图 → 用标准圆/辅助线描边 → 布尔运算切割 → 规范化

## 2. principle-extractor（原则/清单）

- 设计就是找共同点然后结合
- 先画出来，再规范化
- 每个 logo 必须关联名称+行业
- 设计服务于人眼，不是标准尺度
- 保留关键特征，删减其余（减法原则）
- 用大家都懂的符号讲品牌独有的故事
- 给手法起个可记忆的名字（圆切大法/描边大法）

## 3. case-extractor（作者亲用案例）

- 中国银行：中字+铜钱；顺丰：SF+轮胎；国家能源：CE+地平线；万事达卡：双圆叠加；BP：18圆布尔
- 茉莉奶白：笔尖茉莉+圆切花瓣+留白；有杯咖啡：U变咖啡杯+溢满；米奥旺宠物：布尔运算猫狗
- 霸王茶几：12生肖成C字龙纹；潘虎：12生肖成虎

## 4. counter-example-extractor（失败模式/警告）

- 直接"结合一下"不体现行业属性（咖啡D+Y旋转才体现）
- 简单堆砌元素没创意（土鸡汤锅强行放一起被否）
- 直线不适合儿童培训（需换曲线）
- 通用图形缺记忆点（普通咖啡杯难记住，需溢出）
- 人民币配色不可用国徽/人像/文字

## 5. glossary-extractor（术语词典）

- 圆切大法、描边大法、布尔运算、正负形、同构/异形同构、笔画共用/共生、矛盾空间、表现主义字体、有机图形、格式塔、超级符号、记忆点、留白、人民币配色、手电筒上色法、视觉平衡(绝对/相对)、面线面、换位思考
