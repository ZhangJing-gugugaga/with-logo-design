|---|---|---|

| 布尔运算 | 图形相加/相减/相交生成新形 | 加减法·BP 石油 |

| 笔画共用 / 共生 | 共享相同/近似笔画连接多字 | 笔画相同就能一起用 |
| 矛盾空间 | 阴影错位制造空间幻觉 | 矛盾空间字体 logo |
| 表现主义字体 | 去笔画/拆散/替换/模糊表意 | 第十一集 |
| 有机图形 | 不规则、随性、自然感的图形 | 有机图形手法 |
| 格式塔 | 线条规律组合让大脑补全图形 | 线条的格式塔心理学 |

| 视觉平衡 | 绝对对称 vs 相对平衡、视觉补偿 | 视觉平衡术 |
| 设计减法 | 去细节保留关键特征 | 设计减法 |
| 面线面 | 点线面抽象概括 | 第七集·点线面 |
| 谐音切入点 | 从名字谐音/字义切入创意 | 学会找切入点 |
| 换位/换思维 | 常见图形换角度重读 | 换个思维看问题 |
