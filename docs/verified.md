## 淘汰单元（写入 rejected/）

- **人民币配色直接复用国徽/人像/文字** — 违规风险，作者视频中也明确说明"不能用上面的国徽、人像、文字等"，只保留"色系借鉴"
- **"趁我还不火"接单系列（15 条无口播）** — 方法论密度低，仅作为行业案例参考，不单独成模块
- **"我们来做下面这个 logo"空泛引导** — 无实质方法论内容

## 判定说明

- V1 跨域：多数单元在 2 条以上独立视频出现（如"正负形"出现于 4+ 条），满足
- V2 预测力：每个单元都提炼出"什么场景用什么手法"的可迁移规则
- V3 独特性：维兹的手法命名（圆切大法、描边大法、手电筒上色法）和"行业元素+字母结合"范式具有鲜明个人特征，非通用常识
