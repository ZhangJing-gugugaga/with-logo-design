## 内部张力项（作者辩证用法，非淘汰）
- **极简 vs 多元素**：作者两套都在大量用，按品牌调性取舍 → 写入 SKILL.md B 段"内部张力"
- **直线 vs 曲线**：作者明确按受众情绪选择（儿童培训直线改曲线案例）→ 同上
- **人民币配色合规**：作者立场 vs 法规（只用色系）→ 同上

## 淘汰单元（写入 rejected/）

- **人民币配色直接复用国徽/人像/文字** — 违规风险，作者视频中也明确说明不能用，仅保留"色系借鉴"
- **"趁我还不火"接单系列（15 条无口播）** — 方法论密度低，仅作为行业案例参考
- **"我们来做下面这个 logo"空泛引导** — 无实质方法论内容

## 判定说明

- V1 跨域：多数单元在 2 条以上独立视频出现（如"正负形"出现于 4+ 条），满足
- V2 预测力：每个单元都提炼出"什么场景用什么手法"的可迁移规则
- V3 独特性：维兹的手法命名（圆切大法、描边大法、手电筒上色法）和"行业元素+字母结合"范式具有鲜明个人特征，非通用常识
- 证据分级依据：专集视频（单集完整示范=单源；专集+其他视频佐证=多源）
